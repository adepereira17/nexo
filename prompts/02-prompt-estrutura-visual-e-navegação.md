# Prompt 02 — Estrutura Visual e Navegação do NEXO

**Ferramenta:** Lovable  
**Referência:** Prompt Mestre NEXO  
**Prioridade:** P0  
**Etapa:** Fundação visual e estrutural

## Objetivo

Construa a estrutura inicial da aplicação web NEXO, um assistente inteligente de finanças pessoais.

Nesta etapa, concentre-se na arquitetura visual, navegação, identidade gráfica e organização dos componentes.

Não implemente ainda a lógica financeira completa ou integrações reais com inteligência artificial.

## 1. Estrutura principal

Crie uma aplicação com layout profissional e responsivo.

A estrutura deverá contemplar:

- Sidebar de navegação no desktop.

- Cabeçalho com identificação do produto.

- Área principal de conteúdo.

- Navegação adaptada para dispositivos móveis.

- Identificação visual da página atual.

- Componentes compartilhados entre os módulos.

A navegação principal deverá conter:

1. Dashboard

2. Movimentações

3. Análises

4. Metas

5. NEXO AI

Cada item deverá direcionar para sua respectiva página, sem recarregamentos desnecessários.

## 2. Identidade visual

Aplique a identidade definida no Prompt Mestre:

- Azul-marinho: #111827

- Roxo: #8B5CF6

- Verde-lima: #A3E635

- Fundo claro: #F8FAFC

Diretrizes:

- Visual minimalista e moderno.

- Aparência de produto SaaS profissional.

- Tipografia legível.

- Espaçamentos consistentes.

- Cards com bordas discretas.

- Ícones padronizados.

- Hierarquia visual clara.

- Uso moderado de sombras.

Evite aparência de dashboard genérico.

O produto deve possuir identidade própria.

## 3. Componentes compartilhados

Crie componentes reutilizáveis para:

- Sidebar.

- Header.

- Navegação mobile.

- Cards de indicadores.

- Títulos de páginas.

- Botões.

- Campos de formulário.

- Badges de categorias.

- Estados vazios.

- Containers de gráficos.

- Mensagens informativas.

Evite duplicar estruturas visuais entre páginas.

## 4. Dashboard inicial

Crie a primeira versão visual do Dashboard.

Deverá apresentar:

- Mensagem de boas-vindas.

- Indicadores de receitas, despesas e saldo.

- Gráfico demonstrativo de despesas por categoria.

- Gráfico de evolução financeira.

- Resumo das metas.

- Área de acesso rápido ao NEXO AI.

- Seletor de período.

Utilize dados demonstrativos coerentes.

Identifique claramente os valores como demonstrativos.

## 5. Páginas dos demais módulos

Crie a estrutura inicial das outras quatro páginas.

**Movimentações**

- Título e descrição.

- Botão de nova movimentação.

- Área de filtros.

- Tabela ou lista demonstrativa.

**Análises**

- Título e descrição.

- Indicadores de análise.

- Containers de gráficos.

- Área de comparativos.

**Metas**

- Título e descrição.

- Cards de metas demonstrativas.

- Indicadores de progresso.

- Botão de nova meta.

**NEXO AI**

- Identificação do assistente.

- Área de conversação.

- Campo de mensagem.

- Sugestões de perguntas.

- Espaço para respostas.

Nesta etapa, o campo de conversa poderá ser apenas estrutural. Não simule uma integração real com IA.

## 6. Responsividade

Desktop:

- Sidebar fixa.

- Conteúdo principal organizado em grid.

- Cards distribuídos de maneira equilibrada.

Tablet:

- Navegação adaptada.

- Redimensionamento dos componentes.

Mobile:

- Navegação compacta.

- Cards empilhados.

- Tabelas adaptadas para listas.

- Formulários utilizáveis.

- Gráficos sem cortes.

## 7. Organização técnica

Mantenha a aplicação organizada e modular.

Priorize:

- Componentes reutilizáveis.

- Separação entre páginas e componentes.

- Estilos consistentes.

- Tipagem adequada.

- Rotas organizadas.

- Código simples de manter.

Não concentre toda a aplicação em um único componente.

Não instale dependências desnecessárias.

## 8. Restrições desta etapa

Não implementar:

- Integrações bancárias.

- Open Finance.

- Autenticação real.

- Backend próprio.

- Banco de dados remoto.

- Recomendações de investimentos.

- Agente de IA funcional.

Não altere a identidade visual ou os módulos definidos no planejamento.

## 9. Critérios de conclusão

Considere esta etapa concluída somente quando:

- As cinco páginas estiverem disponíveis.

- A navegação funcionar.

- A identidade visual estiver consistente.

- O Dashboard apresentar informações demonstrativas.

- Os componentes compartilhados estiverem organizados.

- A aplicação funcionar em desktop e mobile.

- Não houver erros visuais evidentes.

- Os elementos estruturais não forem apenas imagens estáticas.

## 10. Entrega da etapa

Ao finalizar:

1. Apresente um resumo da estrutura criada.

2. Informe os componentes reutilizáveis implementados.

3. Liste eventuais limitações.

4. Informe problemas identificados.

5. Não avance automaticamente para a implementação dos módulos.

Aguarde a próxima instrução.
